# Clip plots

Spectrogram + constellation PNGs for the four demo clips, made by
`python scripts/plot_clips.py`:

- `clean-*` — the 5 s clip from track 03, as recorded.
- `noisy-*` — the same clip + white noise: the constellation is
  nearly identical, which is why it still matches.
- `sped-up-*` — the same clip at 1.3×: the dots are all in
  different places, which is why it honestly doesn't match.
- `unknown-*` — a melody from no track in the library.
